# 🚀 AI Network Configuration Compliance Auditor

## 🧠 Overview
A production-oriented AI-driven network automation tool designed to audit, validate, and analyze network device configurations for compliance and security risks.

This system combines **rule-based validation** with **LLM-powered intelligence (Ollama)** to identify misconfigurations, enforce best practices, and generate actionable insights.

---

## ⚡ Key Features

- 🔍 Automated configuration validation using YAML/JSON-based policies  
- 🧠 AI-powered analysis for risk detection and recommendation generation  
- 🚫 Detection of insecure configurations (e.g., Telnet enabled, SSH missing)  
- 📊 Structured PASS/FAIL compliance reporting  
- 📁 CSV report generation for scalable data processing  
- 📈 Power BI dashboard integration for visualization and trend analysis  
- 🔄 Modular and extensible rule engine  

---

## 🛠️ Tech Stack

- **Language:** Python  
- **AI Integration:** Ollama (LLM-based analysis)  
- **Data Processing:** JSON, YAML, CSV  
- **Visualization:** Power BI  
- **Automation Concepts:** Rule Engine, Config Parsing  

---

## 🧩 Architecture

1. Input network configuration files  
2. Parse and normalize configurations  
3. Apply compliance rules (YAML-driven)  
4. Run AI-based analysis for deeper insights  
5. Generate structured compliance results  
6. Export reports and visualize in Power BI
